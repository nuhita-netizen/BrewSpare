# BrewSpare feature set

- Brewery machine/process connectivity map with Green / Yellow / Orange / Red operational risk.
- Click-through asset intelligence and live-condition snapshots.
- Machine → spare-part dependency view.
- Critical Assets panel.
- Required Parts to Order panel.
- Historical spare demand + lightweight forecast.
- Future availability / order-window analysis.
- Supplier lead-time and reliability buffer.
- Excess / slow-moving inventory analysis.
- Inventory carrying-cost calculation.
- Maintenance-priority planner.
- Procurement planning approvals that remain local to BrewSpare.
- Scenario simulator for supplier delay and production changes.
- Analytics-grounded AI brief.
- Synthetic brewery dataset for FL-01 / SP-010 critical scenario and SP-015 overstock scenario.
